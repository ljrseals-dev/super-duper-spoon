# 7. Filing Checklist

- [ ] Confirm inventor list and each contribution (especially verification loop + report schema).
- [ ] Obtain signatures on authorization and rights-holder permission.
- [ ] Record first public-disclosure date of the repo in writing; assess foreign novelty impact.
- [ ] Confirm practitioner status and filing capacity.
- [ ] Confirm micro-entity eligibility and current fee.
- [ ] Run the prior-art search and note results in the file.
- [ ] Confirm no third-party source is reproduced in the specification.
- [ ] Finalize specification, claims, and figures 1–6.
- [ ] Complete PTO/SB/16.
- [ ] File via Patent Center; save receipt and application number.
- [ ] Calendar the 12-month non-provisional deadline.
- [ ] Do not add new matter after filing.
